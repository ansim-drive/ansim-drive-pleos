## 안 되는 것

- ✅ **TTS**: 에뮬레이터의 TTS 엔진이 Android 표준 API로 검색되지 않음(`engines=[]`). 엔진 이름을 직접 지정해도 같음
- ✅ **STT**: 인식 서비스가 듣기 요청만 받고 콜백을 보내지 않음. 호스트 마이크를 켠 상태에서 2회 재현. 마이크 설정 전에는 ERROR 9(권한 부족)가 1회 옴
- ✅ **집 주소**: 지도 앱에 집이 등록돼 있지 않음(좌표 0, 0). 데모 빌드만 가상의 집 좌표 사용
- ✅ **권한 창**: 기어 D에서는 시스템 권한 창이 차단됨. adb로 '허용'을 눌러도 반응이 없어 adb 명령으로 권한을 줌
- 🔸 권한 창을 손으로 눌렀을 때 동작하는지는 미확인
- ✅ **백그라운드**: 내비가 앞에 있는 동안 앱이 멈춤. 앱으로 돌아오면 쌓인 기어 변경이 반영됨
- 주행 요약은 메모리에만 있음 (Room 미구현)
