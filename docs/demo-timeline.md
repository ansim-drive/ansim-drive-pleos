# 시연 리허설 타임라인 (2026-11-11)

에뮬레이터 콜드 부팅 → 앱 데이터 초기화 → 데모 빌드(`-PdemoMode=true`) 설치 후 한 번에 돌린 결과다. 시각은 앱 로그(`adb logcat -v epoch -s AnsimDrive`) 기준이다. 스크린샷은 `docs/screens/`에 있다.

## 주의

1. **권한을 허용한 그 실행은 주행 중에 막힌다.** 첫 리허설에서 권한 창을 띄운 실행 그대로 기어 D로 바꾸자, 앱 화면 대신 Pleos 홈 화면의 "주행 중에는 사용할 수 없습니다"가 떴다. 앱은 뒤에서 계속 동작했다. 같은 상태에서 앱을 새로 실행하면 정상으로 보였다. 촬영 때는 권한 허용 뒤 앱을 한 번 종료했다가 다시 실행한다.
2. **"네"는 음성 인식 오인식으로 들어갔다.** 리허설 두 번 모두, 아무도 말하지 않았는데 Vosk가 잡음을 "네 주세요 그거", "없어 어 주세요 네"로 듣고 YES로 처리했다(질문 후 약 3초). 버튼은 눌리기 전이었다. 원하지 않는 경로 요청이 나갈 수 있으므로, 버튼으로 대답하는 장면을 찍으려면 `-PsttEngine=system`으로 빌드한다(에뮬레이터에서는 음성 인식이 동작하지 않아 버튼만 쓰게 된다).
3. 리허설로 지도 앱에 경로 안내가 남으면 다음 시연에서 헤맴 감지가 쉰다(아이콘 회색). 지도 앱에서 "안내 종료"를 누른다.
4. 앱 DB에 리허설 기록이 남는다. 깨끗한 요약으로 찍으려면 `adb shell pm clear --user 10 com.ansimdrive.pleos` 후 다시 권한을 허용한다(주의 1 포함).

## 촬영 순서 (권장)

1. 에뮬레이터 콜드 부팅. 지도 앱에 경로 안내가 남아 있으면 "안내 종료".
2. `adb shell pm clear --user 10 com.ansimdrive.pleos` → `./gradlew assembleDebug -PdemoMode=true` → `adb install -r app/build/outputs/apk/debug/app-debug.apk`
3. Virtual Console에서 기어 P, Exterior Lights Mode → Low beam (출발 전 한마디용).
4. 앱 실행 → 권한 허용 → **앱 종료 후 다시 실행**.
5. 녹화 시작 → 기어 D → 약 17초 뒤 질문 → "네" → 지도 앱 경로 → 기어 P → 앱 아이콘을 눌러 요약.
